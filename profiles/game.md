# Profile — Game

## Stage 1/2

- target platform / audience
- core loop
- control scheme
- win/lose/progression
- session structure
- content scope
- monetization/economy（适用）

## Stage 3

- input mapping
- HUD/menu/tutorial/pause/death/restart
- level/scene flow
- feedback（animation/VFX/SFX）
- accessibility/control settings（适用）

## Stage 4

- game state/entity model
- save/load/versioning
- deterministic simulation requirements
- asset/content pipeline
- level data format
- performance/frame budget
- platform build/deploy

## Stage 5 拆分

Gameplay Logic / Input / Entity-AI / Level / UI-HUD / VFX-SFX / Save / Balance / Analytics / Tests / Playtest。

## Stage 7

自动测试之外必须有 Playtest；玩法平衡/手感变化是 Design/Requirement Change，不得伪装成普通 Bug Fix。
