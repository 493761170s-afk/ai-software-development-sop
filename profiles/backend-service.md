# Profile — Backend / API Service

## Stage 2/3

无 UI 不代表没有体验设计。定义 caller use cases、API/job lifecycle、错误语义、异步状态、retry/cancel/query behavior。

## Stage 4 必须关注

- OpenAPI/Protocol/Event contract
- authentication/authorization
- idempotency / concurrency
- pagination/filter/sort
- error code taxonomy
- rate limit / timeout / retry
- schema/storage/migration
- background jobs / queues
- observability / SLO
- compatibility/versioning

## Stage 7

contract tests、integration、failure injection（风险适用）、load/performance、security、migration/rollback。
