# Changelog

All notable public changes to AI Software Development SOP are recorded here.

The public repository starts from the 4.1.x workflow line. Earlier private development history is intentionally not imported into this repository.

## [4.1.0] - 2026-09-16

### Public baseline

- Publish the eight-stage traditional SDLC for AI-assisted development.
- Require Stage 1–5 completion before formal product coding.
- Require an independent non-authoring model review between Stage 5 and Stage 6.
- Separate review PASS, owner gate, work authorization, merge, verification, acceptance, and release.
- Provide project-type profiles, templates, change control, incident/hotfix handling, requirement traceability, and root-cause debugging utilities.
- Define Spec Kit integration as `METHODOLOGY_ONLY` by default to avoid duplicate sources of truth.
- Include optional Yunxiao/Projex collaboration modeling rules.
- Publish under Apache-2.0 with a clean public history that excludes private project-specific adapters and private business facts.

### Versioning policy

- Patch: wording/template correction without changing governance gates.
- Minor: compatible capabilities, profiles, adapters, or templates.
- Major: changes to authorization, testing, release, or pre-coding gate semantics.
