# Spec Kit Integration Policy

默认 `METHODOLOGY_ONLY`。

## 方法映射

- Constitution → Engineering Constitution + Project Profile / AGENTS
- Specify → Product SOT 中的 what/why/acceptance
- Clarify → explicit open questions / decisions
- Plan → Technical Design / Contracts
- Tasks → WBS / Live Tracker
- Analyze → Stage Gate / targeted consistency audit

## 禁止默认行为

- 不自动 `specify init`
- 不自动创建第二套 `.specify` SOT
- 不把 Figma 当 Product Scope
- 不把 PROPOSED technical notes 当 APPROVED contract
- 不把 `tasks.md` 和 Live Tracker 双边维护
- 不调用 native implement 执行整个 feature 以绕过 Work Item 授权
- Converge 新发现的任务不自动实现
